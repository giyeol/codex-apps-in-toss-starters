# Codex에 붙여 넣을 글

오전에 만든 웹페이지 초안의 글을 이 폴더 `src/content`에 넣어요. 앱을 처음부터 다시 만들지 마세요. 먼저 `SERVICE_BRIEF.md`를 읽고 아래 글을 사용해요.

> 먼저 바꿀 파일과 바꿀 범위를 말해 주세요. 화면에 보이는 글은 `src/content`에서만 바꾸고, 앱 이름과 대표 색상은 `pnpm setup`으로 `service.config.json`에 넣으며, `src/platform`은 수업에서 수정하지 마세요. 한 번에 하나만 바꾸고, 끝나면 `pnpm check` 결과를 짧게 알려 주세요.

화면 글과 예시 내용을 먼저 바꾸고 브라우저에서 확인한 다음, 대표 색상을 바꿔요. 로그인, 결제, 다른 회사 계정, 새 서버는 이 수업에서 하지 않아요.
