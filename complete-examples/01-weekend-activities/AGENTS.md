# AI 실습 범위

이 폴더는 비공식 Apps in Toss 수업용 연습 폴더예요. Toss 공식 지원이 아니에요.

수강생이 컴퓨터용 ChatGPT의 Codex로 **이 폴더**를 연 상태예요. Codex는 코딩 도우미 화면이에요. 오전에 만든 웹페이지 초안의 글을 이 작은 앱에 넣는 단계예요.

## 시작 조건

- node는 `v24.`로 시작하고 pnpm은 `11.9.0`이어야 해요. `v25`는 쓰지 마세요. 둘 다 이 컴퓨터에서 앱을 실행하는 프로그램이에요.
- 할 일은 `README.md` 순서예요. 붙여넣을 글은 `PROMPTS.md`예요.
- `pnpm install`이 이 폴더에 필요한 도구를 받아요. 다른 프로그램을 전역으로 추가로 깔지 마세요.

## 해도 되는 일

- `src/content` 폴더의 글과 예시 내용
- `pnpm setup`으로 앱 이름과 대표 색상 넣기. 결과는 `service.config.json`에 저장돼요.
- `SERVICE_BRIEF.md`에 적힌 범위의 작은 변경
- 변경 후 `pnpm check`

## 하지 마세요

- 앱을 처음부터 다시 만들기
- `src/platform` 폴더 수정
- 로그인, 결제, 실제 광고 번호, 새 서버, 다른 회사 계정, 앱 뼈대 교체
- 수업용 토스 파일을 `pnpm build`로 만들기. `pnpm build:qr`을 쓰세요.
- 이 폴더 밖의 `tooling/`이나 다른 연습 폴더를 수강생 실습으로 수정하기
