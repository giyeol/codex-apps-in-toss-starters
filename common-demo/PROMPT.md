# PART 2 · 선물 뽑기 HTML 만들기 (Codex에 붙여 넣는 글)

이 폴더의 `PRD.md`를 읽고, 바로 써 볼 수 있는 단일 HTML 파일로 만들어 주세요.

1. 결과물은 이 폴더의 `prototype.html` 파일 하나예요. HTML·CSS·JavaScript만 쓰고 아무것도 설치하지 마세요.
2. 모바일 화면 기준이에요. 제목 `선물 뽑기`, 아래에 3×3 상자 9칸, 위에 `쌓인 금액`을 보여 주세요.
3. 상자를 누르면 화면 전체에 `광고 보는 중…`을 2초 보여 준 뒤, 그 상자에 1~3원 중 하나가 적히고 쌓인 금액이 늘어나요. 연 상자는 다시 못 눌러요.
4. 9개를 다 열면 `9개 다 열었어요! 실제 앱에서는 여기서 토스 포인트로 교환해요.`를 보여 주세요.
5. `처음부터` 버튼으로 초기화돼요. 쌓인 금액은 새로고침해도 남아 있게 브라우저에 저장해 주세요.
6. 로그인, 서버, 진짜 광고, 포인트 지급은 넣지 마세요.
7. 먼저 만들 화면과 동작을 세 줄로 말한 뒤 파일을 만들어 주세요. 끝나면 파일 위치와 직접 눌러 볼 세 가지를 알려 주세요.

## 막혔을 때 붙여 넣는 글

- “상자를 눌러도 아무 일이 없어. 왜 그런지 찾아서 고쳐 줘.”
- “글자가 너무 작아. 제목 24px, 본문 16px 이상으로 키워 줘.”
- “기준본 `index.html`로 돌아가서 다시 3번부터 만들어 줘.”
