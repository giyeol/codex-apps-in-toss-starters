# 오전 공통 자료 — 선물 뽑기

오전에 다 같이 만드는 화면의 재료예요. 컴퓨터용 ChatGPT의 Codex에서 **이 폴더**를 열고 순서대로 써요.

- `PRD.md` — 기획서 예시. 누가, 무엇을, 하지 않을 것 세 줄이 들어 있어요.
- `PROMPT.md` — Codex에 붙여 넣는 글. 강사가 앞에서 같은 글을 써요. 결과는 이 폴더의 `prototype.html`로 나와요.
- `index.html` — 기준본. 처음 상태예요. 막히면 이 파일로 돌아가요.
- `final.html` — 완성본. 오전 끝에 나올 모습이에요. 내 것과 비교해요.

같은 오류에는 10분만 써요. 오후는 자유 주제예요. 준비해 온 아이디어·HTML을 활용하거나 이 순서로 내 주제의 HTML을 만들어요. 화면과 핵심 기능을 확인한 뒤 `starter-kits/03-travel-style-test`에 `REFERENCE.html`로 넣어요.
