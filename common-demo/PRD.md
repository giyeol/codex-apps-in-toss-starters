# 선물 뽑기 — 간단 PRD (수업용 축소판)

> 실제 출시한 「선물 뽑기」를 수업용으로 작게 줄인 예시예요. 실제 앱의 보상 정책·광고 설정과 달라요.

## 1. 사용자 문제

- **누가:** 짬 날 때 1분으로 소소하게 무언가 모으고 싶은 사람
- **문제:** 가입하고 설정하는 순간 귀찮아져요. 열자마자 바로 해야 해요.

## 2. 첫 버전 목표

상자를 열면 바로 금액이 쌓이고, 9개를 다 열면 “바꿀 수 있어요”까지 보여 줘요.

## 3. 이번에 할 것 / 하지 않을 것

- 할 것: 상자 9칸, 열기 전 “광고 보는 중” 2초 표시, 1~3원 적립, 쌓인 금액, 9개 완료 안내, 처음부터
- 하지 않을 것: 로그인, 서버, 진짜 광고, 진짜 포인트 지급, 친구 초대

## 4. 핵심 흐름

`상자 고르기 → 광고 자리 2초 → 금액 적립 → 9개 완료 안내`

## 5. 완료 기준

| 요구사항 | 완료 기준 |
| --- | --- |
| 상자 9칸 | 한 화면에 3×3으로 보인다 |
| 열기 | 누르면 2초 뒤 1~3원이 보이고 쌓인 금액이 늘어난다 |
| 완료 | 9개 다 열면 교환 안내 문장이 보인다 |
| 다시 | “처음부터”로 초기화된다 |

## 6. 오후에 내 아이디어로 바꿀 때

이 문서의 1·3·4만 내 주제로 바꾸면 돼요. 화면 하나, 핵심 행동 하나.
