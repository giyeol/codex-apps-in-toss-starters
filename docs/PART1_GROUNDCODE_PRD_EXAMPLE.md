# 매일 상식 쌓기 — 사용자 발견 기반 간단 PRD

> 실제 출시 사례를 바탕으로 PRD의 기본 형식을 보여주기 위해 재구성한
> 강의용 예시예요. 당시 작성한 원본 PRD가 아니며, 수치와 포인트 정책은
> 검증된 운영값이 아닌 예시로만 사용해요.

## 작성 맥락

- **발견한 신호:** 주변의 5060 사용자가 걷기·퀴즈형 리워드 서비스와 짧은
  참여 흐름에 이미 익숙해요.
- **추가 관찰:** 초기 퀴즈가 어렵다는 반응이 있었고, 난이도를 조정한 뒤
  사용자 반응이 좋아졌어요.
- **작성 목적:** 사용자 관찰을 첫 버전의 문제, 가설, 범위, 요구사항으로
  연결하는 형식을 확인해요.
- **SERVICE_BRIEF 연결:** 실습용
  [`SERVICE_BRIEF.md`](../tooling/base/SERVICE_BRIEF.md)의 사용자·문제·핵심
  행동·완료 상태·주요 화면·제외 범위를 한 단계 더 구체화한 문서예요.

## 1. 사용자 문제

- **대상 사용자:** 매일 부담 없이 문제를 풀고 작은 성취를 느끼고 싶은 5060 사용자
- **문제:** 문제가 어렵거나 과정이 복잡하면 재미보다 실패 부담을 먼저 느껴요.

## 2. 가설과 목표

부담 없는 상식 문제를 하루 5개씩 제공하고, 모두 푼 뒤 정답과 해설을
한번에 확인하게 하면 사용자가 풀이에 집중하면서 작은 성취를 느낄 수 있을
거예요.

첫 버전 목표는 5문제를 차례로 풀고 마지막에 결과를 복습할 수 있게 만드는
것이에요.

## 3. MVP 범위

### 이번에 할 것

- 하루 5문제
- 문제마다 보기 4개 중 하나를 선택하는 방식
- 선택 후 정답을 공개하지 않고 다음 문제로 이동
- 마지막 문제 이후 점수와 문제별 정답·짧은 해설 제공

### 이번에 하지 않을 것

- 랭킹과 경쟁 기능
- 어려운 문제 중심의 학습 과정
- 여러 단계의 회원 설정
- 첫 번째 핵심 흐름과 관계없는 부가 기능

## 4. 핵심 흐름

`오늘의 퀴즈 시작 → 1~5번 답 선택 → 결과 요약 → 문제별 정답·해설`

사용자는 한 화면에서 한 문제에만 답해요. 정답은 마지막에 모아서 보여줘 풀이
중 힌트가 되지 않게 해요.

## 5. 주요 요구사항

| 주요 요구사항 | 완료 기준 |
| --- | --- |
| 오늘의 퀴즈 | 큰 글자와 보기 4개, 현재 순서(예: 1/5)를 한 화면에 보여준다. |
| 연속 풀이 | 답을 선택하면 정답 표시 없이 다음 문제로 이동한다. |
| 결과 복습 | 5번 문제 이후 점수와 문제별 정답·짧은 해설을 보여준다. |

## 6. 출시 후 확인할 것

- 사용자가 문제를 끝까지 푸는지
- 난이도가 부담스럽다는 반응이 있는지
- 다음 날 다시 방문하는 사용자가 있는지

아직 정하지 않은 **포인트 정책**과 **재방문 판단 기준**은 실제 운영 전 확인이
필요해요.

## Figma 구성

Figma에서는 문서와 화면 흐름의 역할을 나눠 두 프레임으로 표현해요.

1. **한 장짜리 간단 PRD:** 사용자 문제, 가설, MVP 범위, 핵심 흐름, 주요
   요구사항과 완료 기준, 출시 후 확인 항목을 한 페이지에 정리해요.
2. **로우파이 부록:** `1/5 문제 → 5/5 문제 → 결과·문제별 복습`의 대표
   경로만 연결해 PRD의 핵심 흐름을 확인해요.

완성된 시각 디자인처럼 꾸미기보다 실제 작업 중인 문서와 구조 확인용 화면처럼
보이게 구성해요. 화면은 TDS 적용 전이며 보상 정책은 이번 범위에서 제외해요.

## 20–30초 제작 과정 녹화안

완성본을 억지로 되돌리지 않고 `SERVICE_BRIEF.md`의 복제본과 Figma 작업용
복제 프레임에서 아래 행동을 실제로 수행해요.

1. **0–6초:** 대상 사용자와 문제를 한 문장씩 입력해요.
2. **6–13초:** 가설과 MVP 범위를 입력해요.
3. **13–21초:** Figma에서 간단 PRD 항목을 정리하고 세 화면 상태를 연결해요.
4. **21–27초:** 한 장짜리 PRD와 로우파이 부록, 사례 출처를 차례로 보여줘요.

녹화 뒤에는 작업용 복제본 대신 정리된 PRD와 Figma 원본을 최종 강의 자료로
사용해요.
