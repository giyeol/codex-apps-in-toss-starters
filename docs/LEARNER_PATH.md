# 하루 순서

오늘 목표는 오전에 만든 웹페이지 초안을 작은 앱에 넣고, 토스에 올릴 파일(`.ait`)을 만든 뒤, 본인 토스 앱에서 QR로 핵심 기능이 되는지 확인하는 것이에요. 심사, 승인, 출시는 그다음 단계예요.

| 시간 | 할 일 | 끝났다는 신호 |
| --- | --- | --- |
| 강의 전 | [준비물](PREPARE.md) | node가 `v24.`로 시작, pnpm `11.9.0`, Codex 로그인, 콘솔, 토스 앱 |
| 10:00–10:40 | 오늘 목표와 앱 종류 고르기 | 쓸 사람 한 명과 그 사람이 할 행동 하나 |
| 10:40–12:10 | 웹페이지 초안 만들기 | 브라우저에서 열리는 초안 |
| 12:10–13:10 | 점심, 아이디어 나누기 | 오후에 반영할 점 한 가지 |
| 13:10–15:10 | 연습 폴더에 초안 글 넣기 | `pnpm install` 뒤 브라우저에 내 글이 보임 |
| 15:10–16:00 | 콘솔에 올리고 QR 확인 | 본인 토스 앱에서 최신 QR이 열림 |
| 16:00–17:00 | 공유와 다음 단계 | 이 앱이 무엇을 하는지 한 문장으로 말할 수 있음 |

## 고른 연습 폴더에서

컴퓨터용 ChatGPT에서 Codex를 열고 **그 폴더**를 연 뒤, `README.md`를 따라요.

1. `SERVICE_BRIEF.md`에 오전에 만든 초안을 기준으로 적어요.
2. `pnpm install`과 `pnpm doctor`를 실행해요. 이 폴더에 필요한 도구가 받아지고, 준비가 됐는지 검사해요.
3. 콘솔에서 앱 영문 이름을 만든 뒤 `pnpm setup`에 넣어요.
4. `pnpm dev`로 컴퓨터 브라우저에서 기본 화면을 봐요.
5. `PROMPTS.md`의 글로 `src/content` 폴더에 초안 글을 넣고 `pnpm check`를 실행해요.
6. `pnpm build:qr`로 첫 `.ait` 파일을 만들어 올리고 QR을 확인해요.
7. 더 바꿨다면 검사와 파일 만들기를 다시 하고, 두 번째 QR에서 확인해요.

막히면 같은 오류에 10분만 쓰고 [복구 안내](RECOVERY.md)의 마지막으로 통과한 단계로 돌아가요.
