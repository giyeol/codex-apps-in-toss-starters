# 수강생 전체 동선

공통 완료선은 오전에 만든 HTML을 선택한 미니앱에 반영하고 새 `.ait` 파일을 만든 뒤, 본인 토스 앱의 최신 QR에서 핵심 기능을 확인하는 것이에요. 검토 요청·승인·출시는 이 완료선과 다른 단계예요.

| 시간 | 할 일 | 통과 증거 |
| --- | --- | --- |
| 강의 전 | [준비물](PREPARE.md) 완료 | Node `v24.`, pnpm `11.9.0`, Codex, 콘솔, 토스 앱 |
| 10:00–10:40 | 오리엔테이션과 앱인토스 유형 | 사용자 한 명과 핵심 행동 하나 |
| 10:40–12:10 | HTML 목업 | 작동하는 HTML |
| 12:10–13:10 | 점심·아이디어 공유 | 반영할 개선점 한 가지 |
| 13:10–15:10 | 스타터 폴더에서 HTML 이식 | `pnpm install` 뒤 브라우저에서 내 문구 확인 |
| 15:10–16:00 | 콘솔 등록, `pnpm build:qr`, QR | 본인 토스 앱 최신 QR |
| 16:00–17:00 | 공유와 다음 단계 | 설명 가능한 핵심 가치 |

## 선택한 스타터 폴더에서

ChatGPT 데스크톱에서 **그 폴더**를 열고 `README.md`를 따라요.

1. `SERVICE_BRIEF.md`를 오전에 만든 HTML 기준으로 채워요.
2. `pnpm install`과 `pnpm doctor`를 실행해요. 이때 Granite·TDS·`ait`가 설치돼요.
3. 콘솔 appName을 준비한 뒤 `pnpm setup`을 실행해요.
4. `pnpm dev`로 기준본을 브라우저에서 확인해요.
5. `PROMPTS.md`로 `src/content`에 HTML 문구를 반영하고 `pnpm check`를 실행해요.
6. `pnpm build:qr`로 첫 `.ait`를 만들고 최신 QR을 확인해요.
7. 더 바꾸면 `pnpm check`와 `pnpm build:qr`을 다시 실행하고 두 번째 QR에서 확인해요.

막히면 같은 오류에 최대 10분만 쓰고 [복구 안내](RECOVERY.md)의 마지막 통과 체크포인트로 돌아가요.
