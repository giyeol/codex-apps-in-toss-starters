# 하루 순서

오늘 목표는 자유 주제로 준비한 내 화면(HTML)을 공통 연습 폴더에 넣어 토스에 올릴 파일(`.ait`)을 만들고, 본인 토스 앱에서 QR로 핵심 기능을 확인한 뒤 검토 요청까지 누르는 것이에요. 미리 준비해 온 아이디어·HTML을 활용해도 되고, 오전에 다 같이 배운 순서로 만들어도 돼요. 심사, 승인, 출시는 그다음 단계예요.

## 오전 — 다 같이 만들기

강사와 같은 순서로 선물 뽑기 화면(상자 열기 → 적립 → 9개 완료)을 HTML 파일 하나로 만들어요. 순서는 누구를 위한 화면인가 → 그 사람이 무엇을 하는가 → Codex에 그대로 말하기 → 브라우저에서 보기예요. 재료는 저장소의 [`common-demo`](../common-demo/README.md) 폴더에 있어요. Codex에서 그 폴더를 열고 `PROMPT.md`의 글을 붙여 넣어요. 막히면 기준본(`index.html`)으로 돌아가고, 완성본(`final.html`)과 비교해요. 같은 오류에는 10분만 써요.

## 오후 — 자유 주제

1. 준비해 온 아이디어를 써도 되고 수업 중 정해도 돼요. 사람 한 명·행동 하나로 범위를 좁히고 세 줄을 적어요. 누가, 무엇을, 하지 않을 것.
2. 준비한 HTML이 있으면 브라우저에서 화면과 핵심 기능을 확인해요. HTML이 없거나 더 만들어야 하면 오전에 배운 순서로 내 주제의 화면을 만들어요. 화면 하나, 할 일 하나예요.
3. 핵심 기능이 되는 것을 확인한 뒤 공통 연습 폴더 `starter-kits/03-travel-style-test`를 컴퓨터용 ChatGPT의 Codex에서 열고 `README.md`를 따라요. 주제는 달라도 전원 같은 폴더를 써요.

## 공통 연습 폴더에서

1. 내 HTML을 그 폴더에 `REFERENCE.html` 이름으로 복사하고, `SERVICE_BRIEF.md`에 세 줄을 옮겨 적어요.
2. `pnpm install`과 `pnpm doctor`를 실행해요. 이 폴더에 필요한 도구가 받아지고, 준비가 됐는지 검사해요.
3. 콘솔에서 앱 영문 이름을 만든 뒤 `pnpm setup`에 넣어요.
4. `pnpm dev`로 컴퓨터 브라우저에서 기본 화면을 봐요.
5. `PROMPTS.md`의 글로 `REFERENCE.html`의 화면을 이 앱의 화면(`src/features/active`)으로 옮기고 `pnpm check`를 실행해요. `src/platform`과 앱 뼈대는 그대로 둬요.
6. `pnpm build:qr`로 첫 `.ait` 파일을 만들어 올리고 QR을 확인해요.
7. 더 바꿨다면 검사와 파일 만들기를 다시 하고, 두 번째 QR에서 확인해요.
8. 콘솔 「앱 출시」에서 검토 요청을 눌러요. 메모는 ‘첫 출시’면 돼요. 승인 뒤 출시 버튼은 다음 단계예요.

막히면 같은 오류에 10분만 쓰고 [복구 안내](RECOVERY.md)의 마지막으로 통과한 단계로 돌아가요.
