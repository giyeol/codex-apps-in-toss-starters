## 데모와 도움

첫 데모는 “초안 글 → 연습 폴더 `src/content` → 브라우저 확인”으로 옮기는 방법을 보여 줘요. 두 번째 데모는 “`pnpm build:qr` → 콘솔에 직접 올리기 → QR”로 토스에서 열리는지를 보여 줘요. 수강생이 해냈다는 증거는 바뀐 `src/content`, 통과한 `pnpm check`, 만들어진 `.ait`, 올린 뒤 최신 QR의 핵심 흐름이에요.

## 복구

설치 문제는 `pnpm doctor`와 `docs/RECOVERY.md`를 먼저 써요. 앱 이름/QR 문제는 설정과 방금 만든 파일을 대조하고, 컴퓨터에서 만들어졌다고 휴대폰 QR이 된다고 보지 않아요. 검토 요청은 전원 공통이 아니며 [QR 이후 다음 단계](REVIEW_NEXT_STEPS.md)로 준비된 분만 이어서 해요.
