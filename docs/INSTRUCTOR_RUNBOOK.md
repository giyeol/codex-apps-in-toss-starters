# 첫 수업 진행 안내

## 수업 전

- Node 24.8.0, pnpm 11.9.0, 각 프로젝트의 `pnpm install`과 `pnpm doctor`를 확인해요.
- 콘솔 workspace만 미리 만들었다면, 수업 당일 오후에 앱 등록과 appName을 완료해요.
- 브라우저, QR/기기, 콘솔, Mock API는 이 문서의 로컬 검증과 별개의 PENDING 증거예요.

## 데모와 도움

첫 데모는 “HTML 문구 → 스타터 `src/content` → 브라우저 확인”으로 이식 루프를 보여줘요. 두 번째 데모는 “`pnpm build:qr` → 수동 업로드 → QR”로 플랫폼 연결을 증명해요. 학생 성공 증거는 변경된 `src/content`, 통과한 `pnpm check`, 생성된 `.ait`, 업로드 후 최신 QR의 핵심 흐름이에요.

## 복구

설치 문제는 `pnpm doctor`와 `docs/RECOVERY.md`를 먼저 사용해요. appName/QR 문제는 설정과 방금 만든 artifact를 대조하고, 업로드·QR은 로컬 빌드 성공으로 추정하지 않아요. Mock API는 별도 HTTPS 검증 전에는 기본 로컬 추천을 사용하며, 로딩·오류·재시도는 이후 확장으로만 다뤄요. 검토 요청은 전원 공통 완료가 아니며 [QR 이후 다음 단계](REVIEW_NEXT_STEPS.md)를 이용해 준비된 수강생만 선택해요.
