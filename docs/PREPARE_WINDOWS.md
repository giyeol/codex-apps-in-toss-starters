# Windows 준비 점검표

[ChatGPT 다운로드](https://chatgpt.com/download/) 또는 Microsoft Store에서 컴퓨터용 앱을 설치하고, Codex를 열어 로그인해요. 수업에서 안내한 ChatGPT 계정으로 준비해요.

- [ ] 이 컴퓨터에서 프로그램을 설치할 수 있어요.
- [ ] node를 설치했고, `node --version`이 `v24.8.0` 이상 `v25` 미만이에요.
- [ ] pnpm을 설치했고, `pnpm --version`이 `11.9.0`이에요.
- [ ] 컴퓨터용 ChatGPT에서 Codex를 열고, 폴더를 고를 수 있어요.
- [ ] Chrome 등 최신 브라우저가 있어요.
- [ ] 최신 토스 앱에 본인 계정으로 로그인한 휴대폰이 있어요.
- [ ] [앱인토스 콘솔](https://apps-in-toss.toss.im/)에 가입하고 내 작업 공간을 만들었어요.

회사 보안 때문에 설치가 막히면 강의 당일까지 미루지 말고, 미리 설치 권한을 받으세요. WSL, 에뮬레이터, 가상머신은 이 수업의 공통 준비물이 아니에요.
