# 준비물

node와 pnpm은 이 컴퓨터에서 앱을 실행하는 프로그램이에요. 아래를 실행해 node가 `v24.8.0` 이상 `v25` 미만이고, pnpm이 `11.9.0`인지 확인해요. `v25`는 이 수업에서 쓰지 않아요.

```bash
node --version
pnpm --version
```

내 컴퓨터 종류에 맞는 표를 먼저 봐요.

- [macOS 준비 점검표](PREPARE_MACOS.md)
- [Windows 준비 점검표](PREPARE_WINDOWS.md)

컴퓨터용 ChatGPT 앱에서 Codex를 열고 로그인해요. 최신 토스 앱에 본인 계정으로 로그인하고, [앱인토스 콘솔](https://apps-in-toss.toss.im/)에 가입한 뒤 워크스페이스를 만들어요. QR을 찍으려면 만 19세 이상이고, 그 워크스페이스 멤버여야 해요. Git은 없어도 돼요.

콘솔에 앱을 등록하고 영문 이름을 정하는 일은 수업 당일에 해요. 미리 아무 이름이나 만들지 마세요. 나중에 폴더 설정과 같아야 해요.

앱을 돌리는 데 필요한 나머지 도구는 연습 폴더에서 `pnpm install`을 할 때 받아져요. 미리 따로 깔지 마세요.

## 수익화까지 해 보고 싶다면 (선택)

당일에는 공식 테스트 광고 자리만 만들어요. 실제 광고 수익까지 이어가려면 아래가 미리 되어 있어야 해요. 없어도 수업은 끝까지 할 수 있어요.

1. 사업자 등록증이 있어요.
2. 앱인토스 콘솔에 정산 정보(사업자 정보와 통장)를 등록했고, 승인이 끝났어요. 승인은 며칠 걸려요.
3. 콘솔에서 광고 ID를 미리 발급받았어요. 발급에 약 2시간 걸려요.

자세한 순서는 [수강생 안내](learner/06-monetization-setup.md)의 「수익화 세팅」을 봐요.

안드로이드 에뮬레이터, 아이폰 시뮬레이터, Sandbox 앱은 이 수업의 공통 준비물이 아니에요.
