# 준비물

node와 pnpm은 이 컴퓨터에서 앱을 실행하는 프로그램이에요. 아래를 실행해 node가 `v24.8.0` 이상 `v25` 미만이고, pnpm이 `11.9.0`인지 확인해요. `v25`는 이 수업에서 쓰지 않아요.

```bash
node --version
pnpm --version
```

내 컴퓨터 종류에 맞는 표를 먼저 봐요.

- [macOS 준비 점검표](PREPARE_MACOS.md)
- [Windows 준비 점검표](PREPARE_WINDOWS.md)

컴퓨터용 ChatGPT 앱에서 Codex(코딩 도우미 화면)를 열고 로그인해요. 최신 토스 앱에 본인 계정으로 로그인하고, [앱인토스 콘솔](https://apps-in-toss.toss.im/)에 가입한 뒤 내 작업 공간(워크스페이스)을 만들어요. QR을 찍으려면 만 19세 이상이고, 그 작업 공간의 멤버여야 해요. Git은 없어도 돼요.

콘솔에 앱을 등록하고 영문 이름을 정하는 일은 수업 당일에 해요. 미리 아무 이름이나 만들지 마세요. 나중에 폴더 설정과 같아야 해요.

앱을 돌리는 데 필요한 나머지 도구는 연습 폴더에서 `pnpm install`을 할 때 받아져요. 미리 따로 깔지 마세요.

안드로이드 에뮬레이터, 아이폰 시뮬레이터, Sandbox 앱은 이 수업의 공통 준비물이 아니에요.
