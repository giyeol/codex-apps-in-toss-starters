## 오전 · 선물 뽑기 HTML

`common-demo/PROMPT.md`의 글을 그대로 써요. 요약하면: PRD를 읽고 `prototype.html` 하나로, 3×3 상자, 누르면 2초 광고 자리 뒤 1~3원, 9개 완료 안내, 처음부터 버튼.

## 오후 · 내 주제 HTML 새로 만들기

> 아래 세 줄로 단일 HTML 파일 `prototype.html`을 만들어 줘. 모바일 화면 기준이고 HTML·CSS·JavaScript만 써. 로그인, 서버, 결제, 진짜 광고는 넣지 마. 먼저 화면과 동작을 세 줄로 말한 뒤 만들고, 끝나면 직접 눌러 볼 세 가지를 알려 줘.
> 누가: (한 사람)
> 무엇을: (핵심 행동 하나와 끝난 뒤 보이는 것)
> 하지 않을 것: (이번엔 뺄 것)

## 오후 · 공통 폴더로 옮기기

`app/PROMPTS.md`의 글을 그대로 써요. 그 폴더의 처음 화면은 오전에 만든 선물 뽑기예요. `REFERENCE.html`을 먼저 복사해 두고요.

## 오류가 났을 때
