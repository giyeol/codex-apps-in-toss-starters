## 콘솔에 넣을 때

- 영문 이름(appName)은 나중에 못 바꿔요. `pnpm setup`에 넣은 값과 같아야 해요.
- 상세 설명이 부제와 비슷하면 반려돼요. 반려 사유를 Codex에 붙여 넣고 다시 써 달라고 해요.
- 검색 키워드는 토스 검색창에서 그대로 검색돼요. 최대 10개.
- 로고는 600×600 PNG. 다크 모드 로고는 안 넣어도 돼요.
