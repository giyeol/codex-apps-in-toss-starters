# 화면 이렇게 잡으면 돼요

## 3초 규칙

앱을 열고 3초 안에 “뭐 하는 앱인지”가 보여야 해요. 첫 화면에 제목 한 줄, 큰 버튼 하나.

## 화면은 3~4개면 충분해요

1. 처음 화면: 제목, 한 줄 설명, 큰 버튼
2. 핵심 행동 화면: 누르고, 고르고, 적는 화면
3. 끝난 뒤 화면: “됐어요” 한 마디와 다음 행동
4. (필요하면) 비어 있거나 실패했을 때 화면

## 첫 사용자를 위해

- 온보딩은 한 줄이면 돼요. “상자를 열면 금액이 쌓여요.”
- 내가 만든 앱은 나한테만 익숙해요. 옆사람에게 3초 보여 주고 뭐 하는 앱인지 물어보세요.
- 포인트나 보상이 있으면, 무엇을 하면 무엇을 받는지 한 화면에서 보여 주세요.

## 토스 안에서는

- TDS 기본 부품(버튼, 목록, 상단 바)을 쓰면 토스 앱처럼 보여요. Codex에 “TDS로 바꿔 줘”라고 해요.
- 글자는 크게, 색은 두세 가지만.
- 한 화면에 결정은 하나.
