# 수익화 세팅 순서 (선택)

오늘은 공식 테스트 광고 자리만 만들어요. 실제 광고 수익까지 가려면 아래 순서예요. 며칠 걸리는 단계가 있어서 미리 해 두면 좋아요.

## 순서

1. **사업자 등록** — 광고 수익 정산은 사업자만 받을 수 있어요.
2. **콘솔 정산 정보 등록** — 앱인토스 콘솔 → 내 정보/비즈니스 월렛에서 사업자 정보와 통장을 넣어요. 승인까지 며칠 걸려요.
3. **광고 ID 발급** — 콘솔의 인앱 광고에서 발급받아요. 약 2시간 걸려요.
4. **광고 그룹 만들기** — 배너·전면·리워드 중 골라 광고 그룹을 만들고, 그 ID를 Codex에게 주면서 “이 자리에 광고를 붙여 줘”라고 해요.
5. **새 .ait 올리고 QR 확인** — 광고가 붙은 화면을 내 토스 앱에서 확인하고 검토 요청해요.

## 광고 세 가지

| 종류 | 언제 | 느낌 |
| --- | --- | --- |
| 배너 | 화면 아래 항상 | 작고 조용해요 |
| 전면 | 한 번 크게 | 흐름 사이에 |
| 리워드 | 보면 보상 | 가장 잘 돼요 |

## 정산

- 예상 수익은 콘솔 인앱 광고 성과에서 매일 오전 10시에 갱신돼요.
- 한 달 치가 다음 달 말에 지급돼요. 5,000원 이하면 다음 달로 넘어가요.

## 넣지 말 것

- 실제 광고 ID를 채팅창이나 공개 저장소에 올리지 마세요.
- 테스트 광고 ID로 수업하고, 실제 ID는 출시 직전에 바꿔요.
