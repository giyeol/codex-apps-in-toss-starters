# 유형별 Codex 프롬프트

먼저 선택 폴더의 `SERVICE_BRIEF.md`를 채운 뒤 요청해요. 모든 요청의 마지막에 다음을 붙여요: “먼저 변경할 파일을 말해 주세요. 수업의 내용은 `src/content`에서만 바꾸고, `src/platform`은 일반 실습에서 수정하지 마세요. 화면 표시명과 대표 색상은 `pnpm setup`으로 `service.config.json`에 설정해요. 완료 후 `pnpm check`를 실행해 결과를 요약해 주세요.”

- 주말 활동: “활동 6개를 내 동네 취향에 맞게 바꾸고 카테고리 3개를 유지해 주세요.”
- 습관 챌린지: “습관명과 응원 문구를 바꾸고 오늘 기록 흐름은 그대로 유지해 주세요.”
- 여행 테스트: “6개 질문의 문구와 UI에 보이는 선택지 점수를 바꾸되 세 결과 범위를 모두 도달 가능하게 유지해 주세요.”
- 선물 찾기: “한국어 조건 문구와 로컬 예비 추천 문구를 내 대상에 맞게 바꾸고 API 주소와 fetch 코드는 바꾸지 마세요.”

starter는 핵심 흐름만 담고, complete는 한 가지 선택 확장을 보여줘요. 선물 찾기의 기본 동작은 로컬 추천이며, Mock API는 별도 HTTPS 검증이 끝난 뒤 사용하는 선택 확장이에요. 전체 재작성, SDK 교체, 로그인, 서버, 결제, 외부 계정 추가는 이 수업 범위가 아니에요.
