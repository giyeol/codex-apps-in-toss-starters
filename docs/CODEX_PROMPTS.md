# 종류별 Codex 글

오전에 만든 웹페이지 초안의 글을, 고른 연습 폴더의 `src/content`에 넣어요. 앱을 처음부터 다시 만들지 마세요. 먼저 그 폴더의 `SERVICE_BRIEF.md`를 채운 뒤 요청해요. 모든 요청 끝에 다음을 붙여요.

“먼저 바꿀 파일을 말해 주세요. 수업에서 바꾸는 글은 `src/content`에만 넣고, `src/platform`은 수정하지 마세요. 화면에 보이는 이름과 대표 색상은 `pnpm setup`으로 `service.config.json`에 넣어요. 끝나면 `pnpm check`를 실행하고 결과를 짧게 알려 주세요.”

- 주말 활동: “활동 6개를 내 동네 취향에 맞게 바꾸고 카테고리 3개는 그대로 둬 주세요.”
- 습관 챌린지: “습관 이름과 응원 글을 바꾸고, 오늘 기록하는 흐름은 그대로 둬 주세요.”
- 여행 테스트: “6개 질문의 글과 보기 점수를 바꾸되, 세 결과가 모두 나올 수 있게 해 주세요.”
- 선물 찾기: “조건 글과 폴더 안 추천 글을 내 대상에 맞게 바꾸고, 인터넷 주소와 받아 오는 코드는 바꾸지 마세요.”

starter는 핵심 흐름만 담고, complete는 기능을 하나 더 보여 줘요. 선물 찾기는 기본적으로 폴더 안 예시로 추천해요. 앱 전체를 다시 쓰기, 로그인, 서버, 결제, 다른 회사 계정 추가는 이 수업 범위가 아니에요.
