# macOS 준비 점검표

공식 [ChatGPT 다운로드 페이지](https://chatgpt.com/download/)에서 데스크톱 앱을 설치하고 Codex를 열어 로그인해요. 강의 안내에서 지정한 ChatGPT 계정과 사용량을 준비해요.

- [ ] macOS에서 프로그램을 설치할 수 있는 관리자 권한이 있어요.
- [ ] Git을 설치하고 `git --version`이 실행돼요.
- [ ] Node.js 24 LTS를 설치하고 `node --version`이 `v24.8.0` 이상 `v25` 미만이에요.
- [ ] pnpm 11.9.0을 설치하고 `pnpm --version`이 `11.9.0`이에요.
- [ ] ChatGPT 데스크톱 앱에서 Codex를 열고 폴더를 선택할 수 있어요.
- [ ] Chrome 또는 Chromium 기반 최신 브라우저가 있어요.
- [ ] 최신 토스 앱에 본인 명의 계정으로 로그인한 스마트폰이 있어요.
- [ ] Apps in Toss 콘솔 가입과 워크스페이스 생성을 완료했어요.

버전이 다르면 임의로 여러 Node 설치를 섞지 말고, 강의 안내에 따라 Node 24를 선택한 뒤 터미널을 다시 열어 확인해요.
