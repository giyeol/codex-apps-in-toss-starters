D1

D2

8/26은 스타터 데모였습니다. HTML 이식 경로로 재리허설이 필요합니다.

D3

D5

결과 공유 방식

출시 전 앱은 남에게 안 열립니다. QR·캠프파이어·프라이빗 링크를 마무리 전에 정합니다.

D6

투표·추첨
