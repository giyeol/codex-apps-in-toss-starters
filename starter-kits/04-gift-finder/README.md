# 상황별 선물 찾기

이 폴더는 오전에 만든 웹페이지 초안을, 토스 앱에서 열어 보는 작은 앱으로 옮기는 연습 폴더예요. 앱을 처음부터 다시 만들지 마세요.

시작하기 전에 컴퓨터용 ChatGPT 앱을 켜고, 그 안에서 Codex를 열어요. Codex는 코딩을 도와주는 화면이에요. Codex에게 **이 폴더**를 열게 해요.

node와 pnpm이 설치되어 있어야 해요. 둘 다 이 컴퓨터에서 앱을 실행하는 프로그램이에요. node는 `v24.`로 시작하고, pnpm은 `11.9.0`이어야 해요. `v25`는 쓰지 마세요.

할 일은 이 문서예요. `START_HERE.md`는 이 예시가 어떤 종류의 앱인지만 적혀 있어요.

## 바꿔도 되는 곳

- 화면에 보이는 글과 예시 내용: `src/content` 폴더
- 앱 이름과 대표 색상: `pnpm setup`을 실행하면 물어봐요. 결과는 `service.config.json` 파일에 저장돼요.
- 오전에 만든 웹페이지 초안의 글과 흐름만 넣어요.

## 바꾸지 마세요

- `src/platform` 폴더. 수업에서 건드리지 않는 부분이에요.
- 로그인, 결제, 실제 광고 번호, 새 서버, 다른 회사 계정 연결, 앱 뼈대 교체

## 순서

1. `SERVICE_BRIEF.md`를 열어요. 누구를 위한 앱인지, 그 사람이 무엇을 하는지를 한 문장씩 적어요. 오전에 만든 웹페이지 초안을 보고 적어요.
2. 이 폴더에서 `pnpm install`을 실행해요. 이 폴더에서 앱을 돌리는 데 필요한 도구가 받아져요. 따로 더 깔 프로그램은 없어요.
3. `pnpm doctor`를 실행해요. 준비가 됐는지 확인하는 검사예요.
4. 앱인토스 콘솔(앱을 등록하는 웹사이트)에서 앱 영문 이름을 만든 뒤 `pnpm setup`을 실행하고 그 이름을 넣어요. 앱 등록은 이 폴더를 연 뒤에 해요.
5. `pnpm dev`를 실행해요. 컴퓨터 브라우저에서 기본 화면을 미리 보는 명령이에요. 끄려면 `Ctrl+C`를 눌러요.
6. `PROMPTS.md`에 있는 글을 Codex에 붙여 넣어요. 오전에 만든 글을 `src/content` 폴더에 넣어 달라고 하면 돼요. 한 번에 하나만 바꾸고, 끝나면 `pnpm check`로 잘못된 곳이 있는지 확인해요.
7. `pnpm build:qr`을 실행해요. 토스 앱에 올려 볼 첫 `.ait` 파일이 만들어져요. 그 파일을 콘솔에 직접 올린 뒤, 본인 토스 앱에서 QR을 찍어 확인해요. 수업에서 쓰는 명령은 `pnpm build`가 아니에요.
8. 글을 더 바꿨다면 `pnpm check`와 `pnpm build:qr`을 다시 하고, 새 파일을 올린 뒤 두 번째 QR에서 바뀐 내용을 확인해요.

막히면 GitHub에서 받은 맨 위 폴더의 [`docs/RECOVERY.md`](../../docs/RECOVERY.md)를 봐요. 이 폴더만 있으면 같은 오류에 10분만 쓰고, 새 복사본에서 다시 시작해요.
